Privacy policy

This policy applies from 9 October 2026.

This policy covers the local tool. The owner runs it on their own computer. Send questions about the tool or these pages to mcandea@gmail.com.

Google access

The tool requests the Google Tasks scope: https://www.googleapis.com/auth/tasks. This lets it read and change Google Tasks. The current tool reads your default task list. It tries to delete marked shopping tasks. You can also run safety tests that create and delete a named test task.

The tool checks task titles for the marker words. It checks unmarked titles in memory. It does not save or print those titles.

Local files

The tool saves a Google refresh token on your computer. It uses this token to access Google Tasks without a new sign-in each time.

The tool saves task IDs and version IDs for marked tasks. It saves the state and time of each step. These files contain no task titles. Safety tests also save the test task's ID and version ID.

The product phrases appear in your terminal. If you save that output, the saved file contains those phrases as well.

Local files stay until you delete them. The tool does not remove old records on its own. You can revoke access through Google Account connections at https://myaccount.google.com/connections. This does not delete the local files.

Sharing

The tool sends requests to Google to sign in and use Google Tasks. It does not send task data or Google tokens to this website or GitHub. It does not sell Google data or use it for ads.

The tool follows the Google API Services User Data Policy. This includes the policy's Limited Use rules.

GitHub hosts these public pages. It can log visits to this site. Its Privacy Statement explains this use. These pages have no sign-in form. They have no scripts that track your use.

Changes

The owner will update this policy before the tool changes how it uses your data.
